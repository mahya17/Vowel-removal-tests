# Vowel Removal Tests

## About
A Python testing project based on CS50's *Testing my twttr* problem set. It includes a `shorten` function that removes all uppercase and lowercase vowels from a string, along with tests to check that the function works correctly.

## How It Works
- Takes a string as input.
- Removes the vowels `A`, `E`, `I`, `O`, `U` and their lowercase equivalents.
- Returns the modified string while preserving other characters.
- Uses `pytest` to test the function with different inputs.

## Testing
Run the tests with:

```bash
pytest test_twttr.py
```
